# Frontend SPA (Vue.js)

## Highlights

- Vue 3 (Composition API) with Vite bundler
- Axios-powered POST call to the FastAPI echo endpoint
- Minimal blue-themed UI matching the "PJ-base" brand

## Getting Started

```powershell
cd code/frontend
npm install
npm run dev
```

Configure backend URL via `vite.config.js` proxy settings or by setting `VITE_API_BASE_URL` and updating the Axios call when extending this template.
