# デプロイガイド

## 本番環境への同一サーバーデプロイ

### 1. フロントエンドのビルド

```powershell
cd code/frontend
npm run build
```

`dist/` フォルダに静的ファイル（HTML, CSS, JS）が生成されます。

### 2. FastAPI で静的ファイルを配信

バックエンドのコードを以下のように修正して、ビルド済みフロントエンドを配信します：

#### `code/backend/app/main.py` に追加

```python
from fastapi.staticfiles import StaticFiles
from pathlib import Path

# 既存のルート定義の後に追加

# フロントエンドの dist フォルダをマウント
frontend_dist = Path(__file__).parent.parent.parent / "frontend" / "dist"
if frontend_dist.exists():
    app.mount("/", StaticFiles(directory=str(frontend_dist), html=True), name="static")
```

### 3. 環境変数の設定

本番環境では以下を設定：

**バックエンド (`.env`)**

```bash
APP_ENV=production
API_V1_PREFIX=/api/v1
```

**フロントエンド (`.env.production`)**

```bash
VITE_API_BASE_URL=
```

※ 空文字列または未設定の場合、相対パスで同じサーバーの API にアクセス

### 4. AWS デプロイ例

#### EC2 / ECS の場合

```dockerfile
# Dockerfile
FROM python:3.12-slim

WORKDIR /app

# Node.js をインストール（フロントエンドビルド用）
RUN apt-get update && apt-get install -y nodejs npm

# バックエンド依存をインストール
COPY code/backend/requirements.txt ./
RUN pip install --no-cache-dir -r requirements.txt

# フロントエンドをビルド
COPY code/frontend ./frontend
WORKDIR /app/frontend
RUN npm install && npm run build

# バックエンドコードをコピー
WORKDIR /app
COPY code/backend ./backend

# 起動
CMD ["uvicorn", "backend.app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

#### Lambda + API Gateway の場合

- フロントエンド: S3 + CloudFront で配信
- バックエンド: Lambda (Mangum を使用)
- API Gateway で `/api/*` を Lambda にルーティング

### 5. CORS 設定の調整

本番環境では CORS を適切に制限：

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://yourdomain.com"],  # 本番ドメインのみ許可
    allow_credentials=True,
    allow_methods=["GET", "POST"],
    allow_headers=["*"],
)
```

### 6. 起動確認

```bash
# 本番起動
uvicorn app.main:app --host 0.0.0.0 --port 8000

# アクセス
# http://your-server:8000/        → Vue.js SPA
# http://your-server:8000/api/v1/ → FastAPI
# http://your-server:8000/docs    → API ドキュメント
```
